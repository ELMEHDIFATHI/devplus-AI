# DevPulse AI 🚀

DevPulse AI est une plateforme d'analyse et d'assistance basés sur l'IA pour les développeurs, structurée en microservices Spring Boot et une interface React.

## 🛠 Tech Stack

* **Frontend:** React, TypeScript, Vite, Tailwind CSS, Zustand
* **Backend:** Java 21, Spring Boot 3.3, Spring Cloud Gateway, Spring AI
* **Infrastructure:** PostgreSQL (pgvector), Redis, MongoDB, Apache Kafka, Docker, Kubernetes
* **CI/CD:** GitHub Actions, SonarQube

## 📂 Structure du Projet

* `frontend/` : Application React (Vite)
* `backend/` : Microservices Java (Maven multi-module)
* `infrastructure/` : Scripts Docker Compose et manifestes Kubernetes
* `.github/workflows/` : Pipelines CI/CD

## 🚀 Démarrage Rapide

### Prérequis
* Java 21+
* Node.js 20+
* Docker & Docker Compose
* Maven 3.9+
